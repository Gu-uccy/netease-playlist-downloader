# 网易云音乐歌单下载助手

这是一个适用于 Chrome、Edge 等 Chromium 浏览器的 Manifest V3 扩展。

## 安装

1. 解压插件 ZIP 文件。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `netease-playlist-downloader` 文件夹。

## 使用

1. 打开 `https://music.163.com/` 并进入歌单详情页。
2. 等待歌曲列表加载完成。
3. 选择标准、较高、极高、无损或 Hi-Res 音质。
4. 点击歌单页面里的“批量下载”，或点击浏览器工具栏中的扩展图标。
5. 可随时点击“暂停任务”；再次点击“继续任务”会恢复队列和本插件仍在进行的下载。
6. 文件保存到浏览器下载目录下的 `网易云音乐/歌单名称/` 文件夹。

文件名由歌名和歌手名组成，例如：

```text
歌曲名称-歌手名称.mp3
合唱歌曲-歌手甲、歌手乙.flac
```

## 说明

- 插件每隔约 700 毫秒提交一首，避免短时间创建过多下载。
- 暂停会停止提交新歌曲，并尝试暂停本插件已经启动且仍在进行的浏览器下载。
- 如果歌曲没有所选品质，网易云接口可能自动回落到该歌曲可用的品质；任务结束时会显示回落数量。
- 文件扩展名根据接口实际返回的格式生成，例如 `.mp3`、`.m4a` 或 `.flac`。
- 插件会在浏览器最终确定下载名称时再次指定文件名，避免使用 CDN 返回的 `obj_xxx` 对象名称。
- 同名文件由浏览器自动追加编号，不会覆盖已有文件。
- 插件会根据地址中的歌单 ID 读取完整歌曲 ID 列表，不依赖网页中的旧版歌曲表格。
- 歌单详情接口可能只返回少量歌曲名称，插件会再按每批 100 首补全其余歌曲资料。
- 音频地址没有返回有效文件时，浏览器会显示对应下载失败。
- 网易云音乐修改页面结构或外链地址后，插件中的页面选择器或下载地址可能需要更新。
